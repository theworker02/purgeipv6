# purgeipv6

Purge lightweight ipv6 statistics from stdin samples.

**Site:** https://theworker02.github.io/purgeipv6/

## Install / run

```bash
git clone https://github.com/theworker02/purgeipv6.git
cd purgeipv6
node src/cli.js
node --test
```
